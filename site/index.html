Agent Stacks

Control what your agent depends on.

An agent is composed of many parts. No two agents have all of the same parts, so behavior differs from user to user.

Agent Stacks is an open specification for shipping all of these parts as one unit.

What problem does this solve?

Imagine that you use the caveman plugin. Its compression skill requires Python 3.10 or newer. However, your machine has Python 3.9.6, so the skill fails when the agent runs it.

Most agents are managed like this, as bespoke snowflakes. In contrast, an agent stack defines all of the parts in code so they run the same everywhere.

Try a reference implementation

Nix reference implementation
nix run github:agent-stacks/claude-code

The command above puts one directory on your machine with all of the parts, then launches the agent stack.

agent-stack-claude-code/
├── bin/claude-code       # the launcher for the stack
└── share/agent-plugins/
    ├── caveman/          # plugin
    │   ├── plugin.json
    │   ├── skills/caveman-compress/scripts/compress.py
    │   └── bin/python3   # the runtime for compress.py
    └── agentmemory/      # plugin
        ├── plugin.json
        ├── mcp.json
        ├── skills/
        └── bin/npx       # the runtime for mcp.json's command

What's on the roadmap?

The Agent Stacks stack is in active development. It currently supports plugins, harnesses, and commands, with new features coming soon.

We are looking for contributors, especially for native support in more package managers and more harnesses. See open development for how to get involved.

Open development

Agent Stacks is developed in public. Flox is the initial sponsor and wrote the first implementation, and we are looking for contributors and collaborators. We are not attached to any particular technology. The specification is a layout on disk; Nix is just one way to produce it.

If you are packaging agent tooling already, or you maintain a harness that has to load components, we are open to collaborating.

  • Specification repository. Read the draft, open an issue, or propose a change.
  • #agent-stacks on Slack. Ask a question or tell us what breaks for you.
